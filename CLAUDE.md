# CircleCare public workspace

This is a public example of a local AI team. Use the named subagents in `.claude/agents/` when requested. Their roles are simulated, not human professional credentials.

Read `team/shared/team-context.md` if it exists; otherwise use `team/shared/team-context.example.md`. Save outputs under `team/<agent>/outputs/` (create the directory when needed). Do not edit `.runtime/` or sample dashboard data; the server owns task status. Do not send messages, publish work, or change external accounts unless the user explicitly requests it. Cite evidence and distinguish findings from assumptions.
